## [0.1.0] - 2026-11-10

### Added
- `tutshot init [path]` writes a sample `tutshot.yml` story (`--force` to overwrite).
- `tutshot render [file]` renders one PNG per step (`{id}.png`) plus a vertical storyboard
  `story.png`; options `--out`, `--theme`, `--scale`, `--sheet/--no-sheet`.
- `tutshot fonts` lists the monospace, CJK and UI fonts that were discovered.
- Story validation with clear errors: required `id`/`command`, safe and unique ids, unknown-key
  suggestions, width and theme checks.
- Three themes: `dusk` (default), `paper`, `nord`.
- macOS-style window chrome, numbered captions, block caret, drop shadow, 2x super-sampling.
- East-Asian-width aware wrapping; CJK fonts discovered on Linux, macOS and Windows, with a clear
  error and install hint instead of tofu when none is installed.
- Font overrides via `TUTSHOT_MONO_FONT`, `TUTSHOT_CJK_FONT`, `TUTSHOT_UI_FONT`, `TUTSHOT_FONT_DIRS`.
- Python API: `load_story`, `parse_story`, `render_story`.
- English, 简体中文 and 日本語 README; screenshots in `docs/images/` generated by tutshot itself.
