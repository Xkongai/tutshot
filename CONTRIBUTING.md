# Contributing to tutshot

Thanks for your interest! Issues and pull requests are welcome.

## Reporting bugs / requesting features

Please use the issue templates on GitHub. For bugs, include your tutshot version, OS, Python
version, the output of `tutshot fonts`, the story file (or a minimal one that reproduces the
problem) and the full error output. If the problem is visual, attach the PNG.

## Development setup

```bash
git clone https://github.com/Xkongai/tutshot.git
cd tutshot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
pytest -q
```

CJK tests are skipped when no CJK font is installed. On Debian/Ubuntu install them with
`sudo apt install fonts-noto-cjk` so the full suite runs.

## Documentation and images

The README is available in nine languages: [English](README.md), [简体中文](README.zh-CN.md),
[日本語](README.ja.md), [Español](README.es.md), [Português (Brasil)](README.pt-BR.md),
[Français](README.fr.md), [Deutsch](README.de.md), [한국어](README.ko.md) and
[Русский](README.ru.md). If you change one, please update the others too (or say in the PR
that a translation still needs updating).

Every image in `docs/images/` is generated by tutshot from the story files in this repository
(`tutshot.yml`, `examples/*.yml`). Please regenerate them rather than editing images by hand:

```bash
bash examples/build_docs.sh
```

Keep demo stories tutorial-clean: use paths like `~/project` or `./docs`, never real machine
paths, user names or tokens.

## Pull requests

- Keep changes focused; one feature or fix per PR.
- Add or update tests in `tests/` for behaviour changes.
- Make sure `pytest -q` passes before opening the PR.
- Update `CHANGELOG.md` under `[Unreleased]`.
